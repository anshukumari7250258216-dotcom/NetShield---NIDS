NetShield Security Platform
{{ version }}

NetShield is an enterprise-grade Network Intrusion Detection & Monitoring System engineered for BCA Computer Science portfolios and SOC operations demonstration.

Architecture Highlights:
  • Session-based analyst authentication and access control
  • Multi-threaded Scapy packet parser with BPF filter support
  • Stateful sliding-window anomaly & reconnaissance detection
  • RFC 1918/4193 CIDR subnet topology arithmetic
  • Zero-dependency SQLite WAL-mode event persistence
  • Themeable Dark/Light Security Operations UI
Ethical Cybersecurity Compliance:

NetShield operates in passive inspection mode and does not conduct unauthorized remote scans or offensive actions. Built for educational and defensive security monitoring.
